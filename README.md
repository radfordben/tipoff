# Tipoff

Terminal TUI for tracking NBA playoffs.

## Installation

```bash
pip install tipoff
# or
uvx tipoff
```

## Usage

```bash
tipoff                    # Start with default 30s refresh
tipoff --refresh-interval 15  # Refresh every 15 seconds
```

## Keybindings

| Key | Action |
|-----|--------|
| h/l | Previous/Next day |
| t | Go to today |
| b | Playoff bracket |
| s | Standings |
| p | Stats leaders |
| m | Teams |
| r | Refresh |
| q | Quit |
